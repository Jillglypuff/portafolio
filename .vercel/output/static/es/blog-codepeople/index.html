Querido Diario, Code for the People 🌸

El diario de desarrollo de Jill

A veces pasamos tanto tiempo aprendiendo frameworks... que olvidamos hacer una pregunta mucho más grande.

¿Quién está construyendo internet?

O tal vez una aún mejor:

¿A quién debería pertenecer internet?

Esas fueron las preguntas que no dejaba de pensar después de ver Code for the People.

Esperaba un documental sobre WordPress.

En su lugar, encontré una historia sobre comunidad, colaboración y por qué el Open Source sigue siendo importante.

Mi primera confusión

Por mucho tiempo, pensé que Open Source simplemente significaba:

"El código es público."

Técnicamente... eso es cierto.

Pero eso es solo el comienzo.

Open Source no se trata solo de publicar código fuente.

Se trata de permitir que miles de personas en el mundo mejoren algo juntas.

Alguien corrige un bug.

Alguien traduce documentación.

Alguien reporta un problema.

Alguien mejora la accesibilidad.

Alguien revisa un pull request.

Alguien escribe tests.

Poco a poco... el software evoluciona.

La Web Abierta

Una de las ideas que más me resonó durante el documental fue la importancia de mantener la web abierta.

Una web abierta significa que los desarrolladores pueden construir.

Los creadores pueden publicar.

Los negocios pueden crecer.

Las comunidades pueden colaborar.

Sin depender completamente de una sola plataforma.

Internet se convirtió en lo que es hoy porque innumerables tecnologías se construyeron abiertamente.

No solo WordPress.

Sino también proyectos como:

Linux. PHP. Git. Node.js. React. Vue. MySQL.

Todos los días construimos sobre el trabajo que alguien más decidió compartir.

A veces olvidamos lo extraordinario que eso es realmente.

Notas Técnicas ✨

Cosas que aprendí mientras veía e investigaba.

1. Open Source desde una perspectiva técnica

Los desarrolladores pueden:

Aprender cómo se construye software real
Reportar problemas
Enviar Pull Requests
Mejorar documentación
Construir plugins o extensiones
Ayudar a revisar código
Compartir ideas con la comunidad

Open Source no significa "software gratuito." Significa que el código fuente está disponible bajo una licencia que permite a los desarrolladores inspeccionar, modificar y contribuir a ello. Eso crea algo mucho más grande que una base de código. Crea un ecosistema.

2. WordPress es mucho más que un CMS

Una vista simplificada se ve así:

Navegador
↓
Tema
↓
Plugins
↓
WordPress Core
↓
PHP
↓
MySQL

Cada capa tiene su propia responsabilidad. WordPress Core provee la base. Los Temas controlan la presentación. Los Plugins extienden la funcionalidad. PHP maneja la lógica de la aplicación. MySQL almacena los datos. Debido a esta arquitectura, los desarrolladores pueden construir casi cualquier cosa sin modificar el Core mismo.

3. Una función que lo cambió todo: Hooks

Las acciones permiten ejecutar código personalizado cuando ocurren eventos específicos:

add_action('init', function () {
    // Se ejecuta cuando WordPress inicializa
});

Los filtros funcionan de manera similar:

add_filter('the_title', function ($title) {
    return strtoupper($title);
});

En lugar de cambiar el código fuente original... personalizas el comportamiento a través de puntos de extensión. Es una de las razones por las que WordPress ha permanecido tan flexible por tantos años.

La comunidad también es parte de la arquitectura

Una cosa que el documental me recordó es que las comunidades son tan importantes como los frameworks.

He tenido la oportunidad de asistir a algunos eventos organizados por la comunidad de WordPress Costa Rica.

Tanto la empresa donde trabajo como el estudio de software del que formo parte son equipos relativamente pequeños.

Por eso, conocer desarrolladores de diferentes empresas, industrias y contextos ha sido increíblemente valioso.

Diferentes perspectivas.

Diferentes desafíos.

Diferentes formas de abordar el mismo problema.

A veces no sales de un meetup con un nuevo framework para aprender.

A veces sales con una forma completamente diferente de pensar.

Y creo que eso es aún mejor.

Una frase se quedó conmigo ✨

Un mensaje aparece a lo largo del documental de diferentes maneras.

Internet le pertenece a todos.

Eso no significa que todos escriban código.

Pero todos se benefician cuando el conocimiento se comparte.

Cuando el software es transparente.

Cuando las comunidades colaboran.

Cuando los desarrolladores se ayudan unos a otros en lugar de competir todo el tiempo.

Esa idea se sintió sorprendentemente refrescante.

Nota personal 🌷

Ver Code for the People me recordó que una de las cosas que más disfruto de la tecnología no es un lenguaje o framework específico.

Son las personas detrás de ellos.

He aprendido mucho de mis compañeros de equipo.

Pero asistir a eventos comunitarios también me ha mostrado cuánto hay por descubrir fuera de los proyectos en los que trabajo todos los días.

Cada conversación.

Cada meetup.

Cada experiencia compartida.

Agrega otra pieza a la forma en que pienso como desarrolladora.

Y honestamente... espero nunca dejar de aprender así.

Resumen técnico 🌸

El éxito de Open Source no es solo sobre calidad de código.

También se trata de:

Documentación. Comunidad. Revisiones de código. Accesibilidad. Control de versiones. Mantenimiento a largo plazo. Conocimiento compartido.

El software no se sostiene con repositorios.

Se sostiene con personas.

Cosas Que Quiero Recordar 💖

  • ✦Open Source es tanto sobre personas como sobre código
  • ✦Cada contribución importa, sin importar cuán pequeña sea
  • ✦Las grandes comunidades crean gran software
  • ✦WordPress es mucho más que un CMS
  • ✦El aprendizaje no solo ocurre a través de documentación—también ocurre a través de conversaciones

Si te interesa el Open Source, WordPress, o simplemente entender por qué las comunidades importan en la tecnología, te recomiendo mucho ver Code for the People.

Solo dura unos 15 minutos, pero te deja con ideas que duran mucho más.
