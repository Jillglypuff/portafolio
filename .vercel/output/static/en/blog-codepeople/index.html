Dear Diary, Code for the People 🌸

A developer diary by Jill

Sometimes we spend so much time learning frameworks... that we forget to ask a much bigger question.

Who is building the internet?

Or maybe an even better one:

Who should the internet belong to?

Those were the questions I kept thinking about after watching Code for the People.

I expected a documentary about WordPress.

Instead, I found a story about community, collaboration, and why Open Source continues to matter.

My first misconception

For a long time, I thought Open Source simply meant:

"The code is public."

Technically... that's true.

But that's only the beginning.

Open Source isn't just about publishing source code.

It's about allowing thousands of people around the world to improve something together.

Someone fixes a bug.

Someone translates documentation.

Someone reports an issue.

Someone improves accessibility.

Someone reviews a pull request.

Someone writes tests.

Little by little... software evolves.

The Open Web

One of the ideas that resonated with me the most throughout the documentary was the importance of keeping the web open.

An open web means developers can build.

Creators can publish.

Businesses can grow.

Communities can collaborate.

Without depending entirely on a single platform.

The internet became what it is today because countless technologies were built openly.

Not just WordPress.

But also projects like:

Linux. PHP. Git. Node.js. React. Vue. MySQL.

Every day we build on top of work that someone else decided to share.

Sometimes we forget how extraordinary that really is.

Technical Notes ✨

Things I learned while watching and researching.

1. Open Source from a technical perspective

Developers can:

Learn how real software is built
Report issues
Submit Pull Requests
Improve documentation
Build plugins or extensions
Help review code
Share ideas with the community

Open Source doesn't mean "free software." It means the source code is available under a license that allows developers to inspect, modify, and contribute to it. That creates something much bigger than a codebase. It creates an ecosystem.

2. WordPress is much more than a CMS

A simplified view looks something like this:

Browser
↓
Theme
↓
Plugins
↓
WordPress Core
↓
PHP
↓
MySQL

Each layer has its own responsibility. WordPress Core provides the foundation. Themes control presentation. Plugins extend functionality. PHP handles the application logic. MySQL stores the data. Because of this architecture, developers can build almost anything without modifying the Core itself.

3. One feature that changed everything: Hooks

Actions allow custom code to run when specific events occur:

add_action('init', function () {
    // Runs when WordPress initializes
});

Filters work similarly:

add_filter('the_title', function ($title) {
    return strtoupper($title);
});

Instead of changing the original source code... you customize behavior through extension points. It's one of the reasons WordPress has remained so flexible for so many years.

Community is part of the architecture too

One thing the documentary reminded me of is that communities are just as important as frameworks.

I've had the opportunity to attend a few events organized by the WordPress Costa Rica community.

Both the company where I work and the software studio I'm part of are relatively small teams.

Because of that, meeting developers from different companies, industries, and backgrounds has been incredibly valuable.

Different perspectives.

Different challenges.

Different ways of approaching the same problem.

Sometimes you don't leave a meetup with a new framework to learn.

Sometimes you leave with a completely different way of thinking.

And I think that's even better.

One sentence stayed with me ✨

One message appears throughout the documentary in different ways.

The internet belongs to everyone.

That doesn't mean everyone writes code.

But everyone benefits when knowledge is shared.

When software is transparent.

When communities collaborate.

When developers help each other instead of competing all the time.

That idea felt surprisingly refreshing.

Personal note 🌷

Watching Code for the People reminded me that one of the things I enjoy most about technology isn't a specific language or framework.

It's the people behind them.

I've learned a lot from my teammates.

But attending community events has also shown me how much there is to discover outside the projects I work on every day.

Every conversation.

Every meetup.

Every shared experience.

Adds another piece to the way I think as a developer.

And honestly... I hope I never stop learning that way.

Technical takeaway 🌸

The success of Open Source isn't only about code quality.

It's also about:

Documentation. Community. Code reviews. Accessibility. Version control. Long-term maintenance. Shared knowledge.

Software isn't sustained by repositories.

It's sustained by people.

Things I Want To Remember 💖

  • ✦Open Source is about people as much as code
  • ✦Every contribution matters, no matter how small
  • ✦Great communities create great software
  • ✦WordPress is much more than a CMS
  • ✦Learning doesn't only happen through documentation—it also happens through conversations

Watch the documentary 🎬

If you're interested in Open Source, WordPress, or simply in understanding why communities matter in technology, I highly recommend watching Code for the People.

It's only about 15 minutes long, but it leaves you with ideas that last much longer.
