The 9 Benchmarks Behind the Score 🌸

Understanding what AI leaderboards are actually testing.

So now we know that the final number isn't a magical "intelligence score."

But there's another question: What are the models actually being tested on?

The Artificial Analysis Intelligence Index v4.1.1 combines nine different evaluations.

And each one asks a very different question.

Think of it like a university entrance exam... except instead of one subject, the AI has to take nine completely different exams.

1🏷️ Agents / Real-world work

GDPval-AA v2 — Can AI Actually Do Professional Work?

GDPval is probably one of the most interesting benchmarks because it moves away from traditional "answer this question" evaluations.

Instead, the model is asked to complete real-world professional tasks.

The current GDPval-AA v2 framework covers 44 occupations across 9 major industries.

The tasks can require the model to create deliverables such as:

📄Documents
📄Presentations
📄Spreadsheets
📄Diagrams
📄Other professional deliverables

The model can also use tools such as shell access and web browsing.

So instead of asking: "Can the model answer this question?", GDPval is closer to asking: "Can the model actually complete a piece of work?"

The results are compared using an Elo-style rating, with human expert performance anchored at 1,000.

That makes this benchmark particularly interesting for the future of AI agents. It isn't just testing knowledge. It's testing execution.

2🏷️ Agents / Finance

τ³-Banking — Can AI Follow Rules and Use Tools?

This one is much more specialized.

τ³-Banking evaluates AI agents in realistic banking customer-support scenarios.

Imagine a customer says: "I need to dispute this transaction."

The agent can't simply write a nice answer. It needs to:

  1. Find the correct banking policy.
  2. Understand the policy.
  3. Determine what action is allowed.
  4. Use the appropriate tools.
  5. Complete the workflow correctly.

The benchmark uses a large knowledge base containing roughly 700 interconnected policy documents and evaluates whether the correct state was actually reached in the backend.

Customer Request↓Search Knowledge Base↓Understand Policy↓Select Tool↓Execute Action↓Backend State

Things I Want To Remember 💖

"A benchmark doesn't measure intelligence in abstract. It measures performance on specific execution tasks."

  • GDPval tests if an AI agent can deliver actual professional work.
  • τ³-Banking tests if an AI agent can follow strict rules and policies in tools.
  • Evaluating real-world execution is much harder—and much more valuable—than testing plain text memory.
