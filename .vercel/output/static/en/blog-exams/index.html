How Do You Give an AI an Exam? 🌸 — Inside the Benchmarks That Test AI Models

GDPval-AA, τ³-Banking, Terminal-Bench, SciCode, Humanity's Last Exam... AI benchmarks have strange names, but what are they actually testing? Let's open the exam.

#Artificial Intelligence#AI Benchmarks#LLM#AI Engineering#Machine Learning

In another article, I talked about AI benchmarks and how those beautiful leaderboards full of numbers are supposed to help us compare models.

And then I realized something.

I had casually mentioned names like GDPval-AA v2, τ³-Banking, Terminal-Bench v2.1, SciCode, Humanity's Last Exam, GPQA Diamond, CritPt, AA-Omniscience, AA-LCR... as if those names explained absolutely anything. 🎀

They don't.

So this time, instead of looking at the final score, I want to open the exam.

What is the AI actually being asked to do?

Because saying: "Model A scored higher than Model B" isn't nearly as interesting as understanding what they were tested on.

🌷 First: What Is a Benchmark?

A benchmark is basically a standardized evaluation.

We give different AI models the same or comparable problems and measure how successfully they solve them.

Very simplified: Input → AI Model → Task → Evaluation → Score.

But there is a problem: Intelligence isn't one single skill.

A model might be excellent at coding but weaker at scientific reasoning. Another might know an enormous amount of information but hallucinate frequently. Another might solve difficult academic questions but struggle to complete a realistic workflow inside software.

So instead of asking: "How intelligent is this AI?", benchmarks let us ask smaller, more useful questions:

  • ❓Can it code?
  • ❓Can it reason?
  • ❓Can it use tools?
  • ❓Can it follow instructions?
  • ❓Can it work with huge documents?
  • ❓Can it complete professional work?
  • ❓Does it know when it doesn't know something?

That is why an AI intelligence index usually combines multiple benchmarks. Think of it like a university transcript. You don't receive one mysterious exam called INTELLIGENCE — 100 points 🌸. You take different subjects (Programming, Science, Math, Research) and your overall performance tells a much richer story.

📑 The 9 Benchmarks Examined

1. GDPval-AA v2

Can AI actually do professional work?

GDPval-AA v2 evaluates models using professional tasks based on OpenAI's GDPval dataset.

Models may need to create things such as:

DocumentsSpreadsheetsPresentationsDiagramsProfessional analyses
Web→Shell→Files→Reasoning→Final deliverable

The Artificial Analysis evaluation uses 220 tasks in an agentic environment.

Suddenly we're testing something much closer to: "Can this AI actually complete work?" rather than "Does this AI know the answer?"

🌸 How is it graded?

GDPval-AA v2 uses anonymized comparisons between outputs that contribute to an Elo rating. Human expert performance is anchored at 1000 Elo.

What is this really testing? Real-world professional usefulness.

2. τ³-Banking

Can the AI follow complicated rules AND take the correct action?

Yes, that symbol is the Greek letter tau. τ³-Banking simulates fintech customer support.

💬

"There's a transaction I don't recognize and I need to dispute it."

Customer request→Find relevant policy→Understand policy→Reason about situation→Use tools→Modify system correctly

Not easy! The agent needs to know which policy applies, whether the customer qualifies, what info is required, which account is involved, and which tools to call in what order.

The knowledge base contains roughly 700 interconnected policy documents (~195,000 tokens) across 21 product categories.

🎀 Being nice doesn't get you the point. The benchmark evaluates the backend state. Perfectly written response + wrong system action = ❌.

3. Terminal-Bench v2.1

Put the AI in a terminal and see what happens

Terminal-Bench evaluates whether an AI agent can complete tasks inside a real terminal environment.

Task→Terminal→Commands→Files / Processes→Working result
works_on_my_machine.sh
🌸✨

Knowing what command SHOULD work isn't the same as successfully using it.

The benchmark verifies whether the environment ends in the expected state using automated tests.

Testing a mixture of: Coding + Tool Use + Reasoning + Execution.

4. SciCode

Can AI write code for scientific problems?

SciCode asks: Can you use programming to solve actual scientific problems?

Scientific Context→Python Implementation→Code Execution→Unit Tests

The benchmark doesn't care that the model sounded like it understood the science. The implementation needs to work.

Testing the intersection between Scientific understanding and Programming ability.

Beautiful explanation + Broken Python = ❌

5. Humanity's Last Exam

The name is dramatic. The questions are worse.

Humanity's Last Exam (HLE) was designed because older academic benchmarks were becoming too easy for frontier models.

Experts contributed extremely challenging questions requiring specialized, expert-level knowledge and reasoning.

This avoids benchmark saturation where models all score 98-99%.

Testing how well frontier AI handles extremely difficult expert-level reasoning.

🎓 Mathematics🎓 Physics🎓 Biology🎓 Computer Science🎓 Engineering🎓 Humanities🎓 Social Sciences

6. GPQA Diamond

Questions where even very smart humans struggle

GPQA stands for Graduate-Level Google-Proof Q&A.

🎓 Biology🎓 Physics🎓 Chemistry

GPQA Diamond is the particularly difficult subset of 198 questions designed to require deep domain knowledge and reasoning that cannot be solved by a quick Google search.

Domain experts performed substantially better than skilled non-experts with internet access. Finding information isn't enough; you need knowledge to understand it.

7. CritPt

Welcome to research-level physics

CritPt focuses on research-level physics reasoning with 198 challenging problems.

Question→Mathematical reasoning→Equation→Computation→Precise numerical result

Testing whether the model can reason through difficult physics problems to precise mathematical results.

8. AA-Omniscience

Does the AI know what it knows?

AA-Omniscience evaluates both knowledge and hallucination behavior.

💬

"Who won the Nobel Prize in Computer Science in 2025?" (There is no Nobel Prize in CS!).

Model A (70/90 correct, invents answers when unsure) vs Model B (70/75 correct, expresses uncertainty when unsure). Model B is much more reliable.

🌷 Does the model know when it doesn't know?

9. AA-LCR

Can the AI actually understand a huge context?

LCR stands for Long Context Reasoning across 10K–100K token documents.

Find→Connect→Reason→Synthesize→Answer

Receiving 100,000 tokens isn't the same as reasoning correctly across them. Large context window ≠ perfect long-context reasoning.

🌸 Now Look at the Whole Exam

This is where everything starts making sense. These benchmarks weren't randomly thrown together; they measure different dimensions.

BenchmarkBasically asks...
GDPval-AA v2Can you do professional work?
τ³-BankingCan you follow policies and correctly use tools?
Terminal-Bench v2.1Can you actually work in a terminal?
SciCodeCan you code scientific solutions that work?
Humanity's Last ExamCan you solve extremely difficult expert questions?
GPQA DiamondCan you reason through graduate-level science?
CritPtCan you solve research-level physics problems?
AA-OmniscienceDo you know things without making things up?
AA-LCRCan you reason across huge amounts of context?

An AI Intelligence Score isn't a single IQ number. It's a composite of Professional Work + Tool Use + Coding + Scientific Reasoning + Knowledge + Reliability + Long-Context Reasoning. 🌷

🎀 Plot Twist: The Exam Already Changed

The benchmark list above belonged to Artificial Analysis Intelligence Index v4.1.1. AI moves ridiculously fast. By September 2026, indices had already updated.

🔄 Terminal-Bench 2.1 was replaced by Terminal-Bench 4.0.
🔄 τ³-Banking was replaced by AutomationBench-AA.
🔄 GPQA Diamond was removed from the index.
🔄 New evaluations like AA-Briefcase and GDP.pdf were introduced.

⚡ Benchmark Saturation

As models improve and score 98-99%, benchmarks lose their ability to distinguish top performers. Researchers constantly create harder tasks, private test sets, and new realistic environments. The exam has to evolve because the students keep getting better. 🌸

💗 So Which Benchmark Is the Most Important?

There isn't one! And that's probably the biggest lesson here.

🎯 Software Development

Terminal-Bench + Coding evaluations

🎯 Document Analysis

Long-Context Reasoning (LCR)

🎯 Customer Support Automation

Tool use + Instruction following + Non-hallucination

🎯 Scientific Research

SciCode + Scientific reasoning benchmarks

The question shouldn't simply be: "Which AI has the highest score?" A much better question is: "Which evaluation measures the capability I actually need?"

🌷 Final Thoughts

Before learning about benchmarks, AI leaderboards look like: 53, 51, 47, 42. And we think 53 is smarter.

Now we can look underneath that number. One model is exceptional at coding, another is better at agentic workflows, another hallucinates less, another handles long documents better.

So the next time you see AI Model — Intelligence Index: 53, don't stop at the number. Click the benchmarks. Look at the tasks. Look at how they're graded.

Because sometimes the most interesting part isn't who passed the exam. It's understanding what was on the exam in the first place. 🌸

Next time you see a score, remember: look at the exam, not just the grade.
